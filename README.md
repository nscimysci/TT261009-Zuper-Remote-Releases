# Zuper Remote — Releases

ไฟล์ติดตั้งและไฟล์อัปเดตอัตโนมัติของ Zuper Remote (รีโมตเครื่องอื่นในวง Wi-Fi เดียวกัน · Mac + Windows)

- ดาวน์โหลดรุ่นล่าสุด: [Releases](https://github.com/nscimysci/TT261009-Zuper-Remote-Releases/releases/latest)
- Mac: `Zuper-Remote-<เวอร์ชัน>-mac.dmg` · Windows: `Zuper-Remote-Setup-x64.exe`
- แอปอัปเดตเองผ่าน `latest.json` — ทุกไฟล์มีลายเซ็น Ed25519 แอปตรวจก่อนติดตั้ง
